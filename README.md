# سيرفر ASMAR

يشغّل: حسابات حقيقية، تأكيد إيميل، لوحة متصدرين أسبوعية، أصدقاء، وبروكسي للأسعار والأخبار.
بدون أي مكتبات خارجية. بيحتاج Node 22.5 أو أحدث. الاختبارات: `npm test` (14 اختبار نجحوا).

## التشغيل محلياً
    DEV=1 SECRET=اي_نص_طويل node server.mjs

## النشر (مثلاً Render.com)
1. ارفع مجلد server على GitHub، وأنشئ Web Service (Node)، أمر التشغيل `node server.mjs`.
2. ضيف المتغيرات:
   - `SECRET` نص عشوائي طويل (إلزامي، وإلا بتنتهي الجلسات عند كل إعادة تشغيل)
   - `PUBLIC_URL` رابط السيرفر (لرابط التأكيد)
   - `ALLOWED_ORIGIN` رابط تطبيقك على Netlify
   - `RESEND_KEY` و`MAIL_FROM` لإرسال إيميل التأكيد (resend.com، بدك دومين موثّق)
   - `TWELVE_KEY` لأسعار حقيقية (twelvedata.com) و`FINNHUB_KEY` للأخبار (finnhub.io)
3. قاعدة SQLite بتنمسح على الخطط المجانية. أضف Persistent Disk وحط `DB=/data/data.db`، أو انقل لـ Postgres.
4. حط رابط السيرفر بمتغير `API` داخل app/index.html وارفع التطبيق من جديد.

## اللي مش مبني بعد (بصراحة)
- **إشعارات خارج التطبيق:** بتحتاج مفاتيح VAPID ومكتبة web-push وربط Service Worker.
- **أسعار حقيقية بالتطبيق:** السيرفر جاهز (`/api/prices` و`/api/news`) بس ما جرّبتهم لأنو بدّهم مفاتيحك، والتطبيق لسا بيستخدم أسعار محاكاة.
- **الحساب الحقيقي:** ما انكتب. بيحتاج موافقة وسيط مرخّص، وتحقق هوية، واستشارة قانونية.
- **منع الغش:** النتيجة بتجي من التطبيق نفسه، فممكن تتزوّر. المسابقات الجدّية بتحتاج تداول محسوب على السيرفر.
- **حماية قبل الإطلاق:** شروط استخدام وسياسة خصوصية، وتحديد معدل أقوى، وحذف الحساب.
